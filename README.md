# TinyTrip Studio

A polished consumer web app for planning tiny weekend trips in minutes.

TinyTrip turns a city, vibe, budget, start time, and available hours into a compact itinerary with:

- timed stops
- estimated costs
- budget-aware substitutions
- packing reminders
- local saved trips
- no account, backend, or API key

The app is local-first and runs entirely in the browser.

## Live-style consumer use case

You have half a day free and do not want to plan a full vacation. TinyTrip creates a lightweight plan that is more useful than a generic attraction list: it balances food, rest, photos/culture/nature, and budget.

## Development

```bash
npm install
npm test
npm run build
npm run dev
```

## Design

The UI uses a warm travel-marketplace style: white cards, generous rounded corners, soft shadows, and a red accent inspired by consumer travel products.
